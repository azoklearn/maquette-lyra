1 Première configuration

À faire une seule fois, sur cet ordinateur. Vous collez votre jeton GitHub et vous choisissez un mot de passe. Le jeton est chiffré avec ce mot de passe et rangé dans ce navigateur. Ensuite, vous ne taperez plus que le mot de passe.
  • Le jeton n'est jamais enregistré dans le dépôt : il ne quitte pas cet ordinateur, sauf pour parler à GitHub.
  • Sans le mot de passe, ce qui est stocké est illisible : ce n'est pas un simple écran de garde, c'est un vrai chiffrement (AES-256-GCM).
  • Créez un jeton « fine-grained » limité au dépôt maquette-lyra, permission Contents : Read and write, et rien d'autre.
  • Choisissez un vrai mot de passe (12 caractères ou plus). C'est lui qui protège le jeton si quelqu'un accède à cet ordinateur.

1 Déverrouiller

Le jeton est déjà enregistré sur cet ordinateur. Entrez votre mot de passe.
